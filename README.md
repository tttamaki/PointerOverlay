# Pointer Overlay

PowerPoint・Keynote などの全画面プレゼン中にも、マウス位置を大きな矢印で示すメニューバー常駐アプリです。

- 動作環境：Apple Silicon（arm64）の Mac、macOS 27.0 以降
- 管理者権限は不要です。ネットワーク通信もしません。
- Dock にはアイコンが出ません。操作はすべてメニューバーのアイコン（カーソル矢印）から行います。

## インストール

1. `PointerOverlay-<バージョン>-arm64.zip` を展開します。
2. 展開した `PointerOverlay.app` を、ホームフォルダの「アプリケーション」（`~/Applications`）にコピーします。
   - `/Applications` に置いても動きますが、その場合は管理者の許可を求められることがあります。

## 初回起動

このアプリは Apple の公証（notarization）を受けていない ad-hoc 署名のアプリです。zip をダウンロード・AirDrop・メールなどで受け取った場合は、そのまま開くと次のように表示されて起動できません。

> 「PointerOverlay」は開いていません。Apple は、"PointerOverlay" に Mac に損害を与えたり、プライバシーを侵害したりするマルウェアが含まれていないことを検証できませんでした。

次のどちらかの方法で開いてください（どちらも初回だけ必要です）。

**方法 A：システム設定から許可する**

1. 一度 `PointerOverlay.app` をダブルクリックし、表示されたダイアログを「完了」で閉じます。
2. 「システム設定」→「プライバシーとセキュリティ」を開き、下の方にある「"PointerOverlay" は Mac を保護するためにブロックされました」の横の「このまま開く」を押します。
3. 確認ダイアログで「このまま開く」を押し、ログインパスワード（または Touch ID）で確認します。

**方法 B：ターミナルで隔離属性を外す**

```sh
xattr -dr com.apple.quarantine ~/Applications/PointerOverlay.app
open ~/Applications/PointerOverlay.app
```

USB メモリや外付けディスクから Finder でコピーした場合は、この手順は通常不要です。

アクセシビリティ・入力監視・画面収録の許可は要求しません。

## 使い方

メニューバーのカーソル矢印アイコンをクリックします。

| メニュー | 動作 |
|---|---|
| ポインタ表示 | 矢印の表示を ON/OFF します（チェックが付いている間は ON） |
| 設定… | 設定画面を開きます |
| 終了 | アプリを終了します |

- 初回起動時は OFF です。2 回目以降は、前回終了したときの ON/OFF に戻ります。
- 全画面のスライドショー中は、マウスを画面最上部に移動するとメニューバーが現れます。

### 設定

| 項目 | 範囲 | 初期値 |
|---|---|---|
| サイズ（矢印の高さ） | 24〜300 pt | 80 pt |
| 色 | 任意（カラーピッカー） | グレー `#808080` |
| 不透明度 | 0〜100% | 100% |

- 変更はすぐに矢印に反映され、自動で保存されます。
- 「初期値に戻す」はサイズ・色・不透明度を初期値に戻します（ON/OFF は変わりません）。
- 不透明度を 0% にすると、矢印は表示されず、追従処理も止まります。

## アンインストール

1. メニューから「終了」します。
2. `~/Applications/PointerOverlay.app` をゴミ箱に入れます。
3. 設定も消す場合は、ターミナルで次を実行します。

   ```sh
   defaults delete jp.ac.nitech.tamaki.PointerOverlay
   ```

## 既知の制約

- 矢印は macOS 標準のポインタに重ねて表示します。標準ポインタは隠さないため、両方が見えます。
- 位置の更新は 20 回/秒です。マウスを速く動かすと、矢印が少し遅れて追いかけます。
- 先端位置の誤差は最大 0.5 pt です。
- メニューバーや Dock、開いたメニューの上にも矢印が重なります（クリックは下に通るので操作には影響しません）。
- ロック画面、ログイン画面、スクリーンセーバーなど、OS が保護する画面には表示されません。
- 画面収録・画面共有・オンライン配信に矢印が映るかは検証していません。
- ログイン時の自動起動には対応していません。必要なら「システム設定」→「一般」→「ログイン項目」に手動で追加してください。

## 開発者向け

- 必要なもの：Xcode 27.2 以降
- ビルド：`PointerOverlay.xcodeproj` を Xcode で開いて実行するか、次を実行します。

  ```sh
  ./scripts/build-release.sh   # dist/ に PointerOverlay.app と zip を作成
  ```

- テスト：

  ```sh
  xcodebuild -project PointerOverlay.xcodeproj -scheme PointerOverlay test
  ```

- 設計と検証記録は [plan.md](plan.md) を参照してください。Debug ビルドでは、メニューの「検証」からウィンドウレベルと `collectionBehavior` を切り替えられます。
